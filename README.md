# 🖥️ Michal Nguyen – Portfolio Website

Toto je osobní portfolio vytvořené jako moderní jednostránkový web pro prezentaci mých projektů, dovedností a kontaktu. Cílem je ukázat mou práci v oblasti webového vývoje a designu.

## ✨ Funkce

- Interaktivní 3D model pomocí `<model-viewer>`
- Vlastní kurzory pro jedinečný vizuální styl
- Tmavé rozhraní s CSS proměnnými
- Sekce: Úvod, Projekty, O mně, Kontakt
- Responzivní design pro mobily i desktop
- CSS animace a efekty při přejetí myší

## 🔧 Použité technologie

- HTML5, CSS3, JavaScript (vanilla)
- `<model-viewer>` pro 3D modely (web components)
- GitHub Pages pro hosting
